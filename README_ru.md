# YouTube Feed Cleaner · 1.5.1

[English](README.md)

Расширение Manifest V3 для Chrome/Chromium: убирает выбранный контент, но не считает любое упоминание «Mix» или «лет назад» основанием для скрытия.

## Установка / обновление

1. Скачайте исходники [с GitHub](https://github.com/dyeness/YT-Feed-Cleaner) или клонируйте репозиторий:
   ```sh
   git clone https://github.com/dyeness/YT-Feed-Cleaner.git
   ```
2. Откройте `chrome://extensions`, включите **Режим разработчика**.
3. Нажмите **Загрузить распакованное расширение** и выберите папку с `manifest.json`.
4. При обновлении замените файлы в той же папке и нажмите **Обновить** на карточке расширения. Затем перезагрузите уже открытые вкладки YouTube: старый content script автоматически не заменяется.
5. Закрепите новый значок расширения на панели браузера. Настройки предыдущей версии сохраняются при обновлении существующей установки; удаление и повторная установка могут их сбросить.

Для использования Node.js и сборка не нужны. При желании `npm run package` создаёт чистую папку `dist/yt-feed-cleaner` без зависимостей и тестов; её тоже можно загрузить в браузер. Не меняйте папку установки при каждом обновлении, если хотите сохранить идентификатор и настройки.

## Фильтры и удобство

- **Джемы:** на всех страницах, только по основной ссылке с RD-плейлистом и дополнительному признаку карточки джема/коллекции. Обычная рекомендация с autoplay `list=RD`, название «Mix» или ссылка в описании не достаточны.
- **Shorts:** отдельно Главная, Поиск и остальные страницы; поддерживаются полки и отдельные карточки. Сам видеоплеер расширение не скрывает.
- **Просмотренные:** порог 1–100%, исключительно по процентной полосе прогресса просмотра миниатюры. Ширина в пикселях и посторонний `#progress` не подходят.
- **Возраст:** произвольное количество дней, 0 выключает. Скрытие строго при возрасте **больше** порога. Дата берётся только из метаданных публикации, не из названия, описания, количества просмотров или aria-label.
- **Длительность:** минимум/максимум в минутах, включая десятичные значения. 0 выключает соответствующую границу; видео ровно на границе остаётся. Неподтверждённая длительность, эфиры и ожидаемые премьеры этим фильтром не скрываются.
- **Прямые эфиры, ожидаемые премьеры и обычные плейлисты:** отдельные переключатели. Одно слово «Премьера» без признака предстоящего события не считается доказательством.
- **Фразы в заголовках:** по одной на строку, поиск буквального вхождения без учёта регистра, не регулярные выражения. Достаточно одной совпавшей фразы.
- **Каналы:** по одному точному названию, `@псевдониму` или полному URL канала на строку. Это не поиск по части имени. Псевдоним/URL сравнивается, только если такой идентификатор доступен в карточке; название может быть неоднозначным — используйте идентификатор, когда возможно.
- **«Никогда не скрывать каналы»:** исключения имеют приоритет над всеми фильтрами, в том числе джемами и Shorts. При наличии исключений вся полка Shorts не скрывается целиком, проверяются отдельные карточки. Неизвестный канал не считается совпадением.
- **Область применения:** фильтры видео отдельно включаются для Главной, Поиска, рекомендаций на странице просмотра и Подписок. По умолчанию — только Главная, как в предыдущей версии. Джемы и Shorts управляются собственными переключателями.
- **Общий выключатель**, сброс фильтров, количество скрытых элементов, причины и примеры скрытых заголовков.
- **Временно показать скрытое:** приостанавливает фильтрацию только текущей вкладки, до возобновления или перезагрузки; настройки не меняются.

Изменения настроек применяются к загруженному content script без перезагрузки. Карточки проверяются заново при SPA-навигации, изменениях текста, основной ссылки, бейджа или полосы просмотра. Скрытие использует собственный CSS-атрибут, не переписывая исходный inline `display` YouTube.

### Язык, SVG, размер текста и распыление

На вкладке **«Интерфейс»**:

- **Язык:** автоматический выбор по языку браузера, принудительный русский или английский. Переключение сразу переводит заголовки, подписи, подсказки, причины скрытия, статусы и ошибки обновлений. Выбранный язык используется также в новых системных уведомлениях и подписи значка. Заголовки видео, сообщения коммитов и названия каналов остаются оригинальными; имя расширения в списке Chrome определяется языком браузера.
- **Размер текста:** обычный 16 px, крупный 18 px (**по умолчанию**) или очень крупный 20 px. Подсказки и кнопки тоже увеличиваются. Настройка относится только к окну расширения.
- **SVG:** `icons/icon.svg` используется непосредственно в интерфейсе и является единственным исходником значка. Для панели расширений и уведомлений Chrome, не поддерживающих SVG, PNG-копии автоматически создаются из SVG командой `npm run icons`.
- **Распыление:** включается отдельным переключателем, по умолчанию выключено. Видимая карточка исчезает слева направо, а фрагменты миниатюры разлетаются частицами; если изображения нет, используются цветные частицы. Скорость — 0,45 / 0,8 / 1,2 секунды. Текст и фильтры от этого не меняются.
- **Уменьшение движения в ОС:** учитывается по умолчанию. Можно отдельно отключить этот запрет, если намеренно хотите анимацию даже при такой настройке ОС.
- Карточки за пределами экрана и в фоновых вкладках скрываются сразу. Одновременно разрешено не больше четырёх эффектов по 48 частиц; при прокрутке или изменении размера окна незавершённые эффекты заканчиваются без оставшихся частиц.
- Выключение фильтрации, отдельного фильтра или включение просмотра скрытого отменяет эффект и возвращает карточку, если больше нет причин её скрывать. Выключение только анимации завершает скрытие мгновенно. Повторно использованная карточка проверяется заново перед завершением эффекта — старый таймер не может скрыть уже другое видео.
- **Сбросить фильтры** сохраняет язык, размер текста, настройки эффекта и оповещений. Каждый фильтр и общий выключатель остаются доступны на вкладке **«Фильтры»**.

Анимация не снимает скриншоты, не читает canvas, не клонирует видеоплееры и не воспроизводит звук; частицы используют уже указанный на странице URL миниатюры. Если визуальный эффект не поддерживается или завершается с ошибкой, работает обычное мгновенное скрытие.

### Ограничения точности

Если нужных метаданных нет, соответствующий фильтр не срабатывает. Это намеренно безопаснее угадывания. Возраст распознаётся по отдельным русским/английским относительным датам публикации. Для округлённых месяцев используется нижняя оценка **28 дней**, для лет — **365 дней**: часть старых видео может остаться, зато пограничные не скрываются по завышенной оценке. Другие языки и неподдерживаемые варианты DOM остаются видимыми. Новая разметка YouTube может потребовать обновления адаптера в `content.js`; абсолютная совместимость со всеми экспериментами YouTube не гарантируется.

## Оповещения об обновлениях

- Проверка при установке/обновлении, запуске браузера, каждые **6 часов** и вручную кнопкой в окне настроек.
- Источник — публичный GitHub API репозитория `dyeness/YT-Feed-Cleaner`; основная ветка определяется через API, а не жёстко задаётся `main`.
- **Новая версия:** последний стабильный Release или версия в `manifest.json`, превышающая установленную. Prerelease-теги не считаются стабильным релизом. Если релизов нет, проверка манифеста продолжает работать.
- **Новый коммит:** изменение вершины основной ветки относительно последней успешной проверки. Первая проверка запоминает исходный SHA и не выдаёт старый коммит за новый. Коммит не означает выпущенную новую версию и не доказывает, что ваша локальная копия устарела.
- Системное уведомление, метка **НОВ / NEW** на значке и отдельные ссылки в окне настроек. Уведомления о коммитах и системные оповещения отключаются независимо; баннер версии остаётся доступен.
- **«Отметить прочитанным»** запоминает идентификатор версии/коммита: повторная проверка того же обновления не возвращает оповещение.
- Ошибки сети не стирают известные обновления. Показываются дата последней успешной проверки и ошибка; при ограничении запросов GitHub действует отсрочка, в том числе для ручной проверки. Когда браузер закрыт или компьютер спит, точный шестичасовой интервал не гарантируется.
- **Автоустановки нет:** исходники меняются вручную. Системные уведомления зависят от настроек ОС и браузера.

## Приватность и разрешения

Настройки и состояние обновлений хранятся локально. Заголовки для диагностики передаются только между вкладкой и окном расширения, не сохраняются и не отправляются в сеть. Нет телеметрии, токенов GitHub, чтения истории или разрешения `tabs`. Проверки обновлений запрашивают только общедоступные данные репозитория на GitHub API/raw; включённый визуальный эффект может повторно использовать адрес уже показанной миниатюры, ничего не отправляя на сторонние сервисы. `storage` нужен для настроек, `alarms` — периодических проверок, `notifications` — оповещений. Content scripts работают на настольном `youtube.com` и `www.youtube.com`; мобильный сайт не поддерживается.

## Разработка и проверки

Node.js 20+ (проверено на Node.js 24):

```sh
npm ci
npm test
npm run check
npm run icons
npm run locales # после редактирования JSON-переводов
npm run package
# Необязательная проверка настоящего расширения в отдельном Chromium:
npx playwright install chromium
npm run test:browser
```

- `shared.js`: нормализация и чистые предикаты фильтрации.
- `content.js`: адаптер DOM, восстановление карточек, диагностика текущей вкладки.
- `dissolve.js`: ограниченное по ресурсам распыление, отмена и очистка эффектов.
- `i18n.js`, `translations.js`: единая локализация окна, оповещений и ошибок; словари генерируются из `_locales`.
- `updates.js`: чистые переходы состояния обновлений.
- `background.js`: GitHub, расписание, дедупликация оповещений и значок.
- `popup.*`, `_locales/`: интерфейс RU/EN.
- `icons/`, `scripts/generate-icons.js`: авторский SVG и воспроизводимые PNG 16/32/48/128.
- `tests/`: регрессии ложных срабатываний, миграции настроек, UI, API-ошибок, лимитов и подтверждений оповещений.

Браузерная проверка загружает настоящее MV3-расширение в **отдельный временный профиль**, использует контролируемые HTML-карточки вместо живого YouTube и проверяет инъекцию, CSS, восстановление, popup, сообщения, service worker и метку NEW. Пользовательский профиль браузера не изменяется. Это не замена проверке всех актуальных вариантов живой разметки YouTube. Также проверяются выбор RU/EN, реальный размер текста, SVG, распыление миниатюры, отмена для заменённой карточки и настройка уменьшения движения. Скриншоты: `dist/popup-preview.png`, `dist/appearance-ru-preview.png`, `dist/appearance-en-preview.png`, `dist/dust-preview.png`.
